## [1.0.0] - не выпущена

Первая публичная версия.

### Добавлено

- Страницы настроек из обычных массивов через два фильтра:
    - `modestox_register_admin_plugin_config` — страница настроек плагина (группы → поля);
    - `modestox_register_global_config` — общая страница «Global Settings» (вкладки → секции → группы → поля).
- Проверка каждой схемы библиотекой `modestox/config-processor`, один раз за запрос.
- Регистрация каждого поля в Settings API со значением по умолчанию и очисткой своего типа.
- 15 типов полей: `text`, `textarea`, `password`, `number`, `boolean`, `yes_no`, `select`, `radio`, `multiselect`, `checkbox`, `datetime`, `dynamic_rows`, `file`, `image`, `infoblock`.
- Зависимости полей (`depends`) на сервере и в браузере, включая цепочки и все типы родителей.
- `modestox_config()` — значения нужного типа со значениями по умолчанию, в админке и на фронте.
- Правила владения на общей странице: вкладки, метаданные секций и групп и пути полей принадлежат одному плагину; другие плагины могут добавлять группы и поля.
- Уведомления в админке об ошибках конфигурации: плагин с ошибкой пропускается, остальные работают.
- Строгие записи регистрации: неизвестные ключи с подсказкой «Did you mean», проверка идентификаторов, зарезервированный префикс `mtx`, совпадение и длина имён опций.
- Свои типы полей через фильтр `modestox_register_field_types`.
- `dynamic_rows`: перемещение строк вверх и вниз; защищённые строки по умолчанию через `x_locked_column`.
- Публичный API для форм других плагинов: `modestox_fields()`, `FormFields`, `FieldView`.
- Стили и скрипты полей под постоянными именами (`modestox-admin-settings`, `modestox-admin-fields`, `modestox-admin-depends`).

### Безопасность

- Сохранённый пароль никогда не выводится на страницу.
- Разметка в текстовых полях сохраняется как есть только у пользователей с `unfiltered_html`, иначе фильтруется через `wp_kses_post`.
- Для сохранения страницы нужно право этой страницы.
